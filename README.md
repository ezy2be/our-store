# Our Store

This is a simple online store project.

## Features

- Product listing
- Shopping cart
- Add to cart system
- Remove items from cart
- Total price calculation
- Single page index.html store

## Cart

The cart is implemented in index.html using JavaScript.

It stores products in memory and updates the cart display dynamically.

## Files

- index.html → main store and cart logic
- README.md → project documentation
